# Under the Tree 0.10.1

Free family Christmas wish-list app for Android and the web/PWA.

## Android

Download **UnderTheTree-0.10.1.apk** from this release and install it on Android.

- Package: `com.undertree.family`
- Version: `0.10.1`
- Version code: `15`
- APK SHA-256: `41ead629ed5417eb2d82a2fc5fec187e547939bc880c59d3e2df711f5a2e746b`
- Signing certificate SHA-256: `b4ccc272fae198e1fabb3a88b8102336285d41d68d5df1931bde5b71f7c4d640`
- Verified signatures: v1, v2 and v3

This APK is a signed 0.10.1 rebuild using the verified native wrapper from 0.10.0 plus the tested 0.10.1 shared app core. It includes the fix for the managed-child setup-code **Copy** crash. The rebuilt APK was structurally verified and signed with the original release key; this exact rebuilt binary has not yet had a fresh physical-device acceptance test.

If updating an existing Under the Tree installation, install over the existing app rather than uninstalling first, so the device keeps its local identity.

## Web / iPhone / iPad

The hosted PWA is available at:

https://under-the-tree-1ee02.web.app

On iPhone/iPad, open it in Safari and use **Add to Home Screen**.
